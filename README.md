# portfolio-simple-website
A responsive personal portfolio website built using HTML to showcase my profile, skills, projects, and contact information. This project demonstrates my understanding of basic web development and the structure of a professional portfolio website.

## Features

* About Me section
* My Interests
* Projects section
* Social media link
* Contact page
* Simple and clean design

## Technologies Used

* HTML5
* CSS3

## Project Structure

* `index.html` – Home/portfolio page
* `contact.html` – Contact page
* `style.css` – Styling for the website

## Purpose

This project was created to practice my basic web development skills and build a simple personal portfolio website.
